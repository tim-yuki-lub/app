|---|---|---|---|
| `shitaku/` | 明日の支度 — 出発時刻から今夜の流れを逆算する | 姉 | https://tim-yuki-lub.github.io/app/shitaku/ |

main に反映すると、1〜2分で公開URLに出る（`.github/workflows/pages.yml`）。
