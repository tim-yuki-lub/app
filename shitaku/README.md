# shitaku（明日の支度）— メモ

姉用。出発時刻から今夜の流れ（お風呂・就寝・起床）を逆算するアプリ。
このファイルは「これから足したいこと・方針」を書き留めておく場所。思いついたら下に足していく。

## やりたいこと（未着手）

### 励まし・応援
- **達成できなかった時に励ます。** 責めない言い方で。まずは定型文をいくつか用意して、そこから選んで出す。AIを使うなら小さな中継を別途足す（サーバーなしの方針は崩さない）。
- **工夫を教えてあげる。** 例：目覚ましを遠くに置く、カーテンを少し開けて寝る、前の晩に服を出しておく、など。うまくいかなかった日や、タスクに合わせてひとこと出す。

### 予定の立て方
- **取る時間の幅を変えられるようにする。** 今は朝の準備・睡眠・お風呂から寝るまでの時間が、設定画面の値で毎日同じ。日によって（または曜日・パターンごとに）変えられるようにしたい。
  - 操作のイメージ：時間の枠（朝の準備・睡眠・お風呂など）は**タップで選ぶ**。**長押し（PCなら右クリック）でその枠を編集**する。チップと同じ操作感にする。
  - 設定画面からでも、画面上の枠からでも、変えやすいところから変えられるようにする。
  - 枠は**消せる**ようにもする（いらない枠は計算から外す）。
- **日付の感覚をつける。** 「今夜」「明日の朝」だけでなく、何月何日・何曜日の予定なのかがひと目で分かるようにする。
- 起きる時間を少しずつ早めていく（失敗しても励ます）。
- パターンを持って予定を立てる（平日／休み前など）。

### ふりかえり
- 何に何分かかったか・伸び代の可視化。

### データ
- データはスマホの中だけなので機種変更で消える。いずれ「書き出し／読み込み」ボタンを付ける。

## 方針
- 本人が続けられることを一番にする。できなかった日も責めない。
- データはスマホの中（localStorage）だけ。サーバー・ログインは作らない。
